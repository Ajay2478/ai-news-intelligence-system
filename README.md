# 🧠 AI News Intelligence System

An AI-powered platform that transforms raw news into structured intelligence.

---

## 🚀 Features

* 📰 News aggregation
* 🧠 NLP processing
* 📊 Real-time analytics
* 🔍 Keyword extraction
* 🧬 Entity recognition
* ⚡ Importance scoring
* 📈 Trending insights

---

## 🧱 Architecture

```
Frontend (Next.js)
      ↓
Backend API (FastAPI)
      ↓
PostgreSQL Database
      ↓
NLP Processing Layer
```

---

## 📸 System Capabilities

* Converts raw text → structured intelligence
* Enables decision-making insights
* Supports scalable data pipelines

---

## ⚙️ Setup

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🧠 Core Pipeline

1. Ingest news
2. Clean + preprocess
3. Extract keywords
4. Extract entities
5. Generate summary
6. Score importance
